    Enumerations¶

    This page is about Pyrofork enumerations. Enumerations are types that hold a group of related values to be used whenever a constant value is required. They will help you deal with those values in a type-safe way and also enable code completion so that you can be sure to apply only a valid value among the expected ones.

    BusinessSchedule

    Business away enumeration used in BusinessInfo.

    ChatAction

    Chat action enumeration used in ChatEvent.

    ChatEventAction

    Chat event action enumeration used in get_chat_event_log().

    ChatJoinType

    How the service message NEW_CHAT_MEMBERS was used for the member to join the chat.

    ChatMemberStatus

    Chat member status enumeration used in ChatMember.

    ChatMembersFilter

    Chat members filter enumeration used in get_chat_members()

    ChatType

    Chat type enumeration used in Chat.

    ClientPlatform

    Valid platforms for a Client.

    FolderColor

    Folder color enumeration used in Folder.

    GiftAttributeType

    Star gift attribute type enumeration used in GiftAttribute.

    GiftForResaleOrder

    Describes order in which upgraded gifts for resale will be sorted.

    ListenerTypes

    Listener type enumeration used in Client.

    MessageEntityType

    Message entity type enumeration used in MessageEntity.

    MessageMediaType

    Message media type enumeration used in Message.

    MessageOriginType

    Message origin type enumeration used in MessageOrigin.

    MessageServiceType

    Message service type enumeration used in Message.

    MessagesFilter

    Messages filter enumeration used in search_messages() and search_global()

    PageBlockType

    Message page block type enumeration used in PageBlock.

    PageBlockListType

    Message page block type enumeration used in PageBlock.

    ParseMode

    Parse mode enumeration used in various places to set a specific parse mode

    PollType

    Poll type enumeration used in Poll.

    ProfileColor

    Profile color enumeration used in update_color() and ChatColor.

    RichTextStyle

    Rich text style enumeration used in RichText.

    SentCodeType

    Sent code type enumeration used in SentCode.

    NextCodeType

    Next code type enumeration used in SentCode.

    UserStatus

    User status enumeration used in User.

    ReactionType

    Reaction type enumeration used in ReactionType.

    ReplyColor

    Reply color enumeration used in update_color() and ChatColor.

    StoriesPrivacyRules

    Stories privacy rules type enumeration used in send_story() and edit_story().

    StoryPrivacy

    Story privacy type enumeration used in Story.
